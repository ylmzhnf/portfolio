* **Color Palette:**
  Dark navy background with warm golden accents (`#0f172a` / `#ffb400`) for a professional yet welcoming look.
* **Typography:**
  * *Poppins* — for readability and general text
* **Layout:**
  Mobile-first approach expanding to desktop with a clean, centered layout and grid-based project section.
