## 🚀Local Development

### Prerequisites
- Node.js (v14+)
- npm or yarn

### Setup & Installation

```bash
# Clone the repository
git clone https://github.com/ylmzhnf/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

The site will be available at `http://localhost:5174`

### Build for Production

```bash
npm run build
```

## 🎨Design Decisions

* **Color Palette:**
  Dark navy background with warm golden accents (`#0f172a` / `#ffb400`) for a professional yet welcoming look.
* **Typography:**
  * *Poppins* — for readability and general text
* **Layout:**
  Mobile-first approach expanding to desktop with a clean, centered layout and grid-based project section.
