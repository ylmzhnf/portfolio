# 🚀 Personal Portfolio Website

**🌐 Live Demo:** [portfolio-liard-three-32.vercel.app](https://portfolio-liard-three-32.vercel.app/)

My personal portfolio website, designed with a fast, secure, and responsive structure using modern web technologies. It is developed to showcase my projects, tech stack, and engineering vision as a Full-Stack Developer.

## ✨ Key Features

- **Dynamic Hero Section:** An engaging introductory area that welcomes users with a captivating typewriter effect.
- **Dynamic Project Showcase:** A grid layout displaying my full-stack projects, the technologies used, and their source codes.
- **Secure Contact Form (EmailJS):** A functional form allowing visitors to send emails directly.
  - 🛡️ Full protection against spam messages is ensured through *Honeypot Bot Protection* and *Rate Limiting* algorithms.
- **Responsive Design:** Flawless appearance across mobile, tablet, and desktop devices with a "Mobile-First" approach.

## 🛠️ Technologies Used

- **Frontend:** React (v18), Vite, Vanilla CSS
- **Tools & Libraries:** React Icons, EmailJS (Mail API)
- **Security & Code Quality:** Custom form validations, ESLint
- **Deployment:** Vercel
